# 🎮 Guessing Game

A simple multiplayer guessing game built with **Node.js**, **Express**, and **Socket.IO**.  
Players can join sessions, set questions, submit guesses, earn points, and rotate the game master.


## 🚀 Features
- Create and join game sessions
- Minimum of 3 players required to start
- Game master sets the question and answer
- Each player has 3 attempts to guess
- Winner earns 10 points
- Scores tracked by player names
- Game master rotates after each round
- Session cleanup when players disconnect

# 🛠️ Tech Stack
 **Backend**: Node.js, Express, Socket.IO
 **Frontend**: HTML, CSS, JavaScript
 **Hosting**: Render (frontend)
